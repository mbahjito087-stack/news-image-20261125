One picture of one day. This front page sums up Wednesday 25 November 2026: Ukraine's confirmed drone strike on a Russian ship in the Gulf of Finland leads, with a Houthi drone striking Riyadh's tallest tower, Trump honouring Rudy Giuliani with the Medal of Freedom, Huawei's conviction in a US court, NATO's early-warning jets for Poland, and the Thanksgiving turkeys Freedom and Feathers getting their reprieve.

## What is in here

- `asset.jpg` — the finished 1024×1024 front page.
- `main.py` — checks the picture (whole JPEG, inside the size limits) and copies it byte-for-byte to the output directory as `entry.png`, then verifies the copy by size, SHA-256 and dimensions. No network, no clock, no randomness: two runs write identical bytes.

## Run it

```sh
python3 main.py
```
